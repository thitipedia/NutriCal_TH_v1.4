# โปรแกรมคำนวณธาตุอาหาร - Nutrient Calculator

โปรแกรมสำหรับคำนวณความเข้มข้นของธาตุอาหารและปริมาณสารเคมีที่ใช้ในการผสมสารละลายธาตุอาหาร

## ฟีเจอร์หลัก

### 1. คำนวณธาตุอาหาร
- **สารเคมี → ธาตุอาหาร**: คำนวณความเข้มข้นธาตุจากปริมาณสารเคมี
- **ธาตุอาหาร → สารเคมี**: คำนวณปริมาณสารเคมีที่ต้องใช้จากความเข้มข้นธาตุที่ต้องการ
- รองรับหน่วย: **mg/L (ppm)**, **g/L**, **%**

### 2. จัดการสูตร
- บันทึกสูตรธาตุอาหารด้วย dropdown (ไม่ต้องพิมพ์ JSON)
- **แก้ไขสูตรที่บันทึกไว้**
- ลบสูตร
- โหลดสูตรเพื่อใช้งานซ้ำ
- บันทึกอัตโนมัติในไฟล์ `nutrient_formulas.json`

### 3. คำนวณสารละลายเข้มข้น (Stock Solution)
- คำนวณปริมาณสารเคมีสำหรับเตรียมสารละลายเข้มข้น
- รองรับการโหลดสูตรที่บันทึกไว้
- กำหนดความเข้มข้น (เช่น 100x, 200x)
- แสดงวิธีเตรียมและอัตราเจือจาง

### 4. ฐานข้อมูลสารเคมี
- ข้อมูลสารเคมี 16 ชนิด
- **มีรหัสผ่านป้องกัน**: `3edcQWERTY`
- **แก้ไขน้ำหนักโมเลกุลของธาตุพื้นฐาน** (N, O, H, P, K, Ca, Mg, S, Fe, Zn, Mn, B, Cu) 🆕
- **แก้ไขน้ำหนักโมเลกุลสารเคมี** (JSON format)
- **คำนวณธาตุอาหารอัตโนมัติ** หลังแก้ไขน้ำหนักโมเลกุล
- **บันทึกถาวร** - ข้อมูลคงอยู่หลังปิดโปรแกรม 🆕
- **รีเซ็ตค่ามาตรฐาน IUPAC** ได้ทันที

### 5. ปรับแต่งการแสดงผล 🆕
- **ปรับขนาดตัวอักษร**: 8-18 pt
- เมนู "มุมมอง" → "ขนาดตัวอักษร"

### 6. ส่งออกข้อมูล 🆕
- **PDF**: เหมาะสำหรับพิมพ์และเก็บถาวร
- **DOCX**: แก้ไขใน Microsoft Word ได้
- **CSV**: เปิดใน Excel สำหรับวิเคราะห์
- ส่งออกจากแท็บที่กำลังเปิดอยู่

## ธาตุอาหารที่รองรับ

- **Nitrate (NO₃)** และ **Ammonium (NH₄)**
- **Phosphorus (P)**
- **Potassium (K)**
- **Calcium (Ca)**
- **Magnesium (Mg)**
- **Sulfur (S)**
- **Iron (Fe)**, **Zinc (Zn)**, **Manganese (Mn)**, **Boron (B)**, **Copper (Cu)**

## วิธีใช้งาน

### การรันโปรแกรม

**ถ้ามี Python:**
```bash
python nutrient_calculator.py
```

**ถ้าใช้ไฟล์ .exe:**
- ดับเบิลคลิก `NutrientCalculator.exe`

### การสร้างไฟล์ .exe

**วิธีที่ 1: ใช้ Batch File (ง่ายที่สุด)**
```bash
# สร้างไฟล์ .exe เดียว
ดับเบิลคลิก: build_exe.bat

# สร้างแบบ Portable (โฟลเดอร์)
ดับเบิลคลิก: build_portable.bat
```

**วิธีที่ 2: ใช้ Command Line**
```bash
# ติดตั้ง PyInstaller
pip install pyinstaller

# สร้างไฟล์ .exe
pyinstaller --clean build.spec
```

ไฟล์ .exe จะอยู่ที่โฟลเดอร์ `dist\`

## ตัวอย่างการใช้งาน

### 1. คำนวณธาตุจากสารเคมี
```
สารเคมี: Calcium Nitrate
ปริมาณ: 945 mg/L
หรือ: 0.945 g/L
หรือ: 0.0945 %

ผลลัพธ์:
- NO3: 520.5 mg/L
- Ca: 160.3 mg/L
```

### 2. คำนวณสารเคมีจากธาตุที่ต้องการ
```
ธาตุเป้าหมาย: K (Potassium)
ความเข้มข้น: 200 mg/L
สารเคมี: Potassium Nitrate

ผลลัพธ์:
- ต้องใช้ Potassium Nitrate: 517.3 mg/L
```

### 3. บันทึกสูตร
```
1. เลือกสารเคมีจาก dropdown
2. ใส่ปริมาณและหน่วย (เช่น 945 mg/L)
3. กด "เพิ่ม"
4. ทำซ้ำสำหรับสารเคมีอื่นๆ
5. ใส่ชื่อสูตร: "Hydroponic Formula A"
6. ใส่คำอธิบาย: "For lettuce growth"
7. กด "บันทึกสูตร"
```

### 4. แก้ไขสูตร (ฟีเจอร์ใหม่!)
```
1. เลือกสูตรที่ต้องการแก้ไข
2. กดปุ่ม "แก้ไข"
3. เปลี่ยนชื่อ/คำอธิบาย
4. เพิ่ม/ลบสารเคมี
5. กด "บันทึกการแก้ไข"
```

### 5. เตรียมสารละลายเข้มข้น
```
สูตร: โหลดจากที่บันทึกไว้
ความเข้มข้น: 100x
ปริมาตร: 1 ลิตร

ผลลัพธ์:
- Calcium Nitrate: 94.5 g
- Potassium Nitrate: 81.0 g
วิธีเจือจาง: 10 ml ต่อน้ำ 1 ลิตร
```

### 6. แก้ไขน้ำหนักโมเลกุลของธาตุ (ฟีเจอร์ใหม่!)
```
1. ไปที่แท็บ "ฐานข้อมูลสารเคมี"
2. ใส่รหัสผ่าน: 3edcQWERTY
3. กด "ปลดล็อค"
4. กด "แก้ไขน้ำหนักโมเลกุลธาตุ"
5. แก้ไขค่าของธาตุ (เช่น N: 14.007 → 14.010)
6. กด "บันทึก"
7. ระบบจะคำนวณธาตุอาหารใหม่อัตโนมัติ:
   - NO₃ = N + (3 × O)
   - NH₄ = N + (4 × H)
8. ข้อมูลจะบันทึกในไฟล์ nutrient_database.json
9. กด "รีเซ็ตค่ามาตรฐาน" เพื่อกลับค่า IUPAC
```
