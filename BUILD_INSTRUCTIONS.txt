================================================================================
       โปรแกรมคำนวณธาตุอาหาร - Nutrient Calculator
              คำแนะนำการสร้างไฟล์ EXE
================================================================================

** อัพเดทฟีเจอร์ใหม่ (เวอร์ชั่นล่าสุด) **
- รองรับหน่วยความเข้มข้น: mg/L, g/L, %
- บันทึกสูตรด้วย dropdown (ไม่ต้องพิมพ์ JSON)
- แก้ไขสูตรที่บันทึกไว้ได้
- ฐานข้อมูลสารเคมีมีรหัสผ่านป้องกัน (3edcQWERTY)
- แก้ไขน้ำหนักโมเลกุลได้และบันทึกถาวร (ข้อมูลคงอยู่หลังปิดโปรแกรม)
- ปรับขนาดตัวอักษร (8-18 pt)
- ส่งออกข้อมูล: PDF, DOCX, CSV

================================================================================

มี 2 วิธีในการสร้างโปรแกรมให้ใช้งานได้โดยไม่ต้องติดตั้ง Python:

================================================================================
วิธีที่ 1: สร้างไฟล์ .exe เดียว (แนะนำ - ง่ายที่สุด)
================================================================================

1. ติดตั้ง Python (ถ้ายังไม่มี)
   - ดาวน์โหลดจาก: https://www.python.org/downloads/
   - เลือกติดตั้งพร้อม "Add Python to PATH"

2. ดับเบิลคลิกไฟล์:
   > build_exe.bat

3. รอให้โปรแกรมสร้างเสร็จ (ใช้เวลาประมาณ 1-2 นาที)

4. ไฟล์ .exe จะอยู่ที่:
   > dist\NutrientCalculator.exe

5. คัดลอกไฟล์ NutrientCalculator.exe ไปใช้งานได้เลย
   - ไฟล์เดียว ใช้งานได้ทันที
   - ขนาดประมาณ 15-20 MB

================================================================================
วิธีที่ 2: สร้างแบบ Portable (โฟลเดอร์)
================================================================================

1. ดับเบิลคลิกไฟล์:
   > build_portable.bat

2. รอให้โปรแกรมสร้างเสร็จ

3. โฟลเดอร์โปรแกรมจะอยู่ที่:
   > dist\NutrientCalculator\

4. สามารถคัดลอกทั้งโฟลเดอร์ไปใช้งานที่เครื่องอื่นได้
   - เปิดใช้งานที่: NutrientCalculator.exe ในโฟลเดอร์
   - เริ่มใช้งานเร็วกว่าวิธีที่ 1 เล็กน้อย

================================================================================
วิธีใช้งานแบบไม่ต้องสร้าง EXE
================================================================================

ถ้ามี Python อยู่แล้ว สามารถรันโปรแกรมได้โดยตรง:

   > python nutrient_calculator.py

================================================================================
การแก้ปัญหา
================================================================================

ปัญหา: PyInstaller ไม่พบ
แก้ไข: รันคำสั่ง
   > pip install pyinstaller

ปัญหา: สร้าง .exe แล้วรันไม่ได้
แก้ไข:
   - ตรวจสอบ Windows Defender / Antivirus (อาจบล็อก)
   - ลองรันแบบ Administrator
   - ลองใช้วิธีที่ 2 แทน

ปัญหา: ไฟล์ nutrient_formulas.json หายหลังปิดโปรแกรม
แก้ไข: ไฟล์จะบันทึกในโฟลเดอร์เดียวกับที่รัน .exe
        ให้วาง .exe ในโฟลเดอร์ที่ต้องการเก็บข้อมูล

================================================================================
ขนาดไฟล์
================================================================================

- ไฟล์ .exe เดียว (build_exe.bat): ~15-20 MB
- แบบ Portable (build_portable.bat): ~20-30 MB (หลายไฟล์)

================================================================================
ไฟล์ที่โปรแกรมสร้างขึ้น
================================================================================

โปรแกรมจะสร้างไฟล์ต่อไปนี้ในโฟลเดอร์เดียวกับ .exe:

1. nutrient_formulas.json - สูตรที่บันทึกไว้
2. nutrient_database.json - ฐานข้อมูลสารเคมีที่แก้ไข (น้ำหนักโมเลกุล)

**ข้อมูลเหล่านี้จะคงอยู่แม้ปิดและเปิดโปรแกรมใหม่**

================================================================================
การใช้งานฟีเจอร์ใหม่
================================================================================

การแก้ไขน้ำหนักโมเลกุลของธาตุ (ฟีเจอร์ใหม่!):
1. ไปที่แท็บ "ฐานข้อมูลสารเคมี"
2. ใส่รหัส: 3edcQWERTY
3. กด "แก้ไขน้ำหนักโมเลกุลธาตุ"
4. แก้ไขค่าของธาตุพื้นฐาน (N, O, H, P, K, Ca, Mg, S, etc.)
5. กด "บันทึก" - ระบบจะคำนวณธาตุอาหารอัตโนมัติ
6. กด "รีเซ็ตค่ามาตรฐาน" เพื่อกลับค่า IUPAC

การแก้ไขฐานข้อมูลสารเคมี:
1. ไปที่แท็บ "ฐานข้อมูลสารเคมี"
2. ใส่รหัส: 3edcQWERTY
3. กด "แก้ไขฐานข้อมูลสารเคมี (JSON)"
4. แก้ไข JSON (เช่น เปลี่ยน "mw": 236.15)
5. กด "บันทึก"
6. ข้อมูลจะถูกบันทึกในไฟล์ nutrient_database.json

การปรับขนาดตัวอักษร:
- เมนู "มุมมอง" → "ขนาดตัวอักษร" → เลือก 8-18 pt

การส่งออกข้อมูล:
- เมนู "ส่งออก" → เลือก PDF, DOCX หรือ CSV
- จะส่งออกเฉพาะแท็บที่กำลังเปิดอยู่

================================================================================
หมายเหตุ
================================================================================

- ไฟล์ที่สร้างจะทำงานบน Windows เท่านั้น
- ไม่ต้องติดตั้ง Python ในเครื่องที่จะนำไปใช้
- สูตรที่บันทึกจะเก็บในไฟล์ nutrient_formulas.json
- ฐานข้อมูลที่แก้ไขจะเก็บในไฟล์ nutrient_database.json
- ไฟล์ JSON จะอยู่ในโฟลเดอร์เดียวกับที่รัน .exe
- การส่งออก PDF ต้องมี reportlab library
- การส่งออก DOCX ต้องมี python-docx library
